01About Me

Building reliable mobile apps for 6.6+ years

From polished React Native screens to the Node.js APIs behind them — designed, shipped and maintained in production.

I'm a Senior React Native Developer with 6.6+ years of experience designing, developing, optimizing, and deploying scalable mobile applications for iOS and Android. My core stack is React Native, TypeScript, Redux, Expo and GraphQL.

On the backend I work with Node.js, Express.js and MongoDB (plus MySQL and Firebase) — building and integrating REST and GraphQL APIs, JWT authentication and real-time Pusher/WebSocket services, so I can deliver features across the full stack.

I've shipped fintech features like KYC/vKYC, card management, UPI and payments, built real-time systems on Pusher/WebSockets, and hardened apps with SSL pinning, root/jailbreak detection and VAPT remediation.

Beyond code, I own end-to-end releases, mentor junior developers, run code reviews, and work directly with clients to turn business requirements into reliable products.
